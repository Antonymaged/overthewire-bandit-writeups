# OverTheWire Bandit — Security Notes

A collection of personal notes and technical write-ups documenting my progress through the [OverTheWire Bandit wargame](https://overthewire.org/wargames/bandit/).

This repository is part of my hands-on learning journey in cybersecurity, focusing on Linux fundamentals, command-line utilities, file permissions, SSH, and practical problem-solving.

## 🎯 Objectives

- Strengthen my Linux and command-line skills.
- Understand common Linux utilities and their practical applications.
- Develop systematic troubleshooting and problem-solving techniques.
- Document the reasoning behind each solution rather than memorizing commands.
- Practice using Git and GitHub to maintain organized technical documentation.
